## 拍图小建议

1. **画面里带上"环境"比纯截图可信**：比如拍屏幕时把板子、杜邦线一起拍进去。
2. **数值要能看清**：截图别缩太小，关键数字（3.27V / 58%）必须可读。
3. **一张图只说明一件事**：宁可多拍两张，不要在截图上堆标注。
4. **不要改图上的数字**：截图里的数值要和 `docs/测试记录.md` 记录的一致，改过就会前后矛盾。

## 视频说明

`docs/demo/demo.mp4` 是完整演示录屏。

GitHub 的 README 里 mp4 不能在页内直接播放，有两种处理方式：

- **方式 A（推荐）**：把视频拖进任意一个 Issue 的评论框，GitHub 会生成一个 `user-images.githubusercontent.com` 的链接，把那个链接粘到 README 里，就能**页内直接播放**。
- **方式 B**：保留现在这种「点击下载/播放」的链接（README 已写好）。

如果后续能转成 GIF（10 秒以内、控制在 5 MB 内），页内自动播放效果最好。
